# Splitly

A tip and bill splitter in one HTML file, built with the Cursor agent for the Global Hack Week: Hacktoberfest "Build a Mini App with Cursor" challenge.

Open `index.html` in a browser. Enter the bill, pick 10/15/20% or a custom tip, and the number of people. Tip, total and each share update as you type. Optional dark mode (remembered) and a round-each-share-up option that shows the extra it collects.
